# NotebookLM

### Link

**NotebookLM:** https://notebooklm.google.com/notebook/c583b068-44b5-4a68-9148-321b3b2e1795

> Access depends on Google account permissions. If the notebook does not open, request access from the project maintainers.

### Purpose

This notebook is intended to help team members:

* get familiar with the project faster
* search across key Headway materials in one place
* ask questions about conventions, architecture, AI-related docs, and design materials
* reduce time spent manually browsing multiple documents during onboarding

### Recommended use cases

Use the notebook when you need to:

* understand the project structure and conventions
* quickly find answers in existing documentation
* navigate design and product-related materials
* explore AI/project documentation before asking the team
* speed up onboarding for new client, server, or fullstack contributors

### Current source materials

At the moment, the notebook is grounded on the following sources:

* Figma Designs
* Git Conventions
* Source code
* Headway AI Docs
* Supabase Schema

### Notes

* NotebookLM should be used as a **supporting onboarding tool**, not as the single source of truth.
* Always verify important implementation details against the actual repository, current documentation, and active project decisions.
* If new major documents are added to the project, the notebook sources should be updated as well.

### Suggested onboarding flow

1. Open the NotebookLM workspace.
2. Review the attached sources to understand what materials are available.
3. Ask high-level questions first:
   * project overview
   * client/server/fullstack conventions
   * architecture
   * database structure
   * AI-related documentation
4. Cross-check answers in the repository and linked documents.
5. Escalate unclear or outdated points to the team.

### Maintenance

When updating the notebook, make sure that:

* relevant new project docs are added
* outdated files are removed or replaced
* the source list stays aligned with the current project state
* onboarding-critical materials remain included
