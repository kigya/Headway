# Memory Bank

Short-lived and long-lived **project context** for AI work in this repo. It does **not** replace `AGENTS.md` (code policy by path) or `.cursor/rules/` (enforced agent rules).

| File | Role |
|------|------|
| [projectbrief.md](projectbrief.md) | What this repo is and what “done” usually means for AI tasks |
| [productContext.md](productContext.md) | Product-facing facts and open questions (keep small) |
| [techContext.md](techContext.md) | Stack, layout, build checks — grounded in repo docs |
| [systemPatterns.md](systemPatterns.md) | Recurring architecture choices visible in the codebase |
| [activeContext.md](activeContext.md) | Current focus, branch intent, immediate next steps |
| [progress.md](progress.md) | Log of notable AI-workflow or context updates |

Update these files when `/finish-feature` or `/capture-lesson` surfaces durable context; keep reusable anti-patterns in [`.cursor/rules/lessons-learned.mdc`](../rules/lessons-learned.mdc).
