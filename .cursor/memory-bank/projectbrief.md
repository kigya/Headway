# Project brief

Headway is a **Kotlin monorepo**: a Compose Multiplatform **client** (`client/`) and Ktor-based **server** services (`server/`), with shared conventions in root `AGENTS.md` and nested `AGENTS.md` files.

**AI scope:** assist with implementation and reviews **according to** the closest `AGENTS.md` and `.cursor/rules/`, using this Memory Bank for orientation and session-to-session context.

**Human handbook:** GitBook sources live under `.gitbook/` (see root `README.md` for links).
